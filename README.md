# 📊 Telecom Churn Prediction

This project is a Machine Learning application that predicts whether a telecom customer is likely to churn (leave the service) or not.

It uses classification algorithms (such as XGBoost) and is deployed using Streamlit.

---

## 🚀 Project Objective

The main goal is to:
- Analyze customer data
- Train a machine learning model
- Predict customer churn probability
- Help telecom companies reduce customer loss

---

## 🧠 Machine Learning Model

- Algorithm: Randomforest Classifier
- Type: Binary Classification
- Output:
  - 1 → Customer will churn
  - 0 → Customer will not churn
